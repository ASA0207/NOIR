# NOIR CLUB · New Edition (2026)

## 배포 방법
1. 이 ZIP을 압축 해제하세요.
2. `index.html`, `style.css`, `script.js`, `assets/`를 GitHub 저장소 **최상위**에 올리세요.
3. GitHub 저장소 → Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: `main`, Folder: `/(root)` → Save.
4. 별도 `.github/workflows` 파일은 포함되어 있지 않습니다. 기존 워크플로가 있으면 충돌 여부를 확인하고 불필요한 Pages 워크플로는 제거하세요.

## 포함 기능
- 접속 시 반드시 나타나는 입장 화면 (음악 입장 / 조용히 입장)
- 사용자 제공 Mr.Kitty – After Dark 음원; 70초 하이라이트부터, 음량 25%, 반복
- 음악 On/Off, 슬라이더 볼륨
- 디스코드 초대 https://discord.gg/PGfDmjN9Y7
- 키보드 `asa` 비밀 연출, 규칙 검색, 경고 안내, 채널 소개

참고: 브라우저 보안 정책 때문에 사용자 클릭 이전에 소리 있는 음악을 자동으로 재생할 수 없습니다. 음악과 함께 입장을 클릭하면 재생됩니다. 음원 재배포 및 공개 이용 권한은 사용자가 확인해야 합니다.

**주의:** GitHub Pages의 'deployment already in progress' 오류는 GitHub 배포 상태 충돌로서 사이트 ZIP 자체를 바꿔도 남을 수 있습니다.
